# FRPROGRAMITY · Oficina Virtual

Una oficina 3D donde un **equipo de agentes de inteligencia artificial** trabaja como una empresa de verdad: recibe pedidos, se reparte el trabajo, programa, revisa la calidad y la seguridad, y entrega el resultado al cliente.

> Desarrollado por **FRPROGRAMITY** · República Dominicana

## Qué hace

- **Equipo que trabaja en serio.** Cada proyecto pasa por plan → textos y diseño (en paralelo) → código → control de calidad → revisión de ciberseguridad → entrega. Cada paso lo hace un agente distinto, según su puesto y sus habilidades.
- **Memoria de la empresa.** Una guía de estilo que todos los agentes leen y las lecciones de cada proyecto aprobado.
- **Cotizaciones automáticas** con los precios de FRPROGRAMITY, listas para enviar por WhatsApp o descargar.
- **Recepción inteligente.** Detecta qué puestos le faltan al equipo y trae candidatos para entrevistar.
- **Sala de Programación** para los proyectos grandes y **Laboratorio de Mecatrónica** para robótica y electrónica.
- **Laboratorio (🔬 Lab):**
  - Simulador de **Arduino** con código real (C++): LEDs, botones, potenciómetros, sensores, servos, motores, LCD, brazo robótico y monitor serie. Descarga el `.ino` y la lista de materiales para montarlo de verdad.
  - **Robot** 2WD que esquiva obstáculos o sigue una línea.
  - **Retos** de Arduino con comprobación automática.
  - Calculadoras de **electrónica** (Ley de Ohm, resistencias, divisores, baterías…).
  - **Algoritmos**: 16 ejercicios con pruebas automáticas.
- **Música:** emisoras de salsa y corridos en vivo, y álbumes de Fuerza Regida en su reproductor oficial.
- Todo lo que crea el equipo incluye **Política de Privacidad, Términos, Cookies** y el crédito **"Desarrollado por FRPROGRAMITY"**.

## Cómo usarla

1. Abre la página (o `index.html` en tu computadora).
2. Conecta una IA en **🤖 Asistente → ⚙**: Gemini es gratis con una clave de Google AI Studio.
3. Pídele algo al asistente, por ejemplo: *"Haz una web para una pizzería"* o *"Cotiza una web con reservas para Barbería Leo"*.

Sin IA conectada, la oficina funciona con su generador local.

## Privacidad

No hay servidor: todo se guarda **solo en tu navegador**. Las claves de IA no salen de tu equipo, salvo para hablar directamente con el proveedor que elijas (Google o Anthropic).

## Tecnología

HTML, CSS y JavaScript sin servidor · three.js para la oficina 3D · Tailwind CSS · Claude (Anthropic), Gemini (Google) o WebLLM como motores de IA.
